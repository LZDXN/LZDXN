**🤖 WrapperAI**

*A business's private data sanitizer.*

Businesses increasingly rely on generative AI while handling sensitive internal information. WrapperAI was an early exploration of a lightweight, employee-side privacy layer that **identifies information users want removed, sanitizes data before it reaches external AI services, and surfaces potential security and compliance risks**.

Key idea: **make private data useful for AI-assisted work without unnecessarily exposing it as training data for external models.**
